# qThroneMobile 2.4.4

- Исправлена разметка редактора подписки: окно больше не сдвигается за нижнюю границу экрана, и список можно долистать до последнего поля.
- Высота редактора рассчитывается по доступной области окна и пересчитывается при её изменении, в том числе при появлении клавиатуры.
- Перетаскивание окна остаётся только на верхней ручке. Стиль плиток и переключатели сохранены.

CSQTT остаётся только на исходном 2.5.0 Legacy. APK устанавливается поверх предыдущей версии с сохранением профилей и настроек. В релизе публикуются только APK и стандартные архивы исходников.
