# qThroneMobile 2.2

- Добавлен SSTP: ручной ввод, импорт ссылок и подписок, буфер обмена, QR-коды и открытие `sstp://` из других приложений. Поддерживаются логин/пароль, SNI и явное разрешение недоверенного сертификата. Клиент собран из исходников для всех трёх архитектур Android.
- Исправлен импорт HTML-страниц подписок CSQTT 2.5.0 Legacy с QR-кодом. Повторяющиеся ссылки на странице добавляются один раз. Для каждой новой сессии CSQTT передаются поколение и соль для управления подключением и его завершения.
- Иконки меню подписки окрашены в цвет темы. Редактор подписки открывается снизу; при закрытии сохраняется предупреждение о несохранённых изменениях.
- Дополнительные параметры подписки перенесены в «Обновить», этот раздел расположен выше «Отображения серверов». Настройки фронтового и посадочного прокси сохранены, в том числе для обычных групп.
- Плитки настроек, деплоя и управления серверами приведены к общему стилю с небольшими скруглениями. Сохранён отклик на нажатие, выровнена длительность переходов и устранено ожидание загрузки VPS перед первым кадром окна деплоя.

Подписка с самоподписанным HTTPS-сертификатом требует включения соответствующего разрешения в её редакторе. Эта настройка применяется только к выбранной подписке.
