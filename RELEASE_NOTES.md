Первый стабильный релиз qThrone для Android — 1.0.

- Число в поле ручного MTU выровнено по началу линии ввода.
- Настройки маршрутизации показываются уже с именем текущего профиля: убрано позднее появление подписи и изменение высоты плитки при открытии.
- Включены улучшения бета-версий: округлые окна и меню с поддержкой тем, компактный список профилей, плавные переходы настроек, резервное копирование, редакторы новых протоколов и независимое отображение текущего пинга.
- При работающем VPN обновление подписок не создаёт отдельное системное уведомление; основное уведомление подключения сохраняется.
- Доступны APK для arm64-v8a, armeabi-v7a, x86_64 и universal.

Основа: ThroneForAndroid 2.0.2, ветка main, коммит [d5882d52](https://github.com/throneproj/ThroneForAndroid/commit/d5882d52a9080775b849049de802496fdaa1c155).
