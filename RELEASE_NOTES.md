• Исправлен внутренний переход между бета-версиями: код APK теперь возрастает, подпись и совместимость обновления проверяются до публикации.
• Исправлена работа капчи VK после остановки VPN и выхода из проверки. Добавлен крестик закрытия; фоновые тесты подписок не открывают капчу поверх интерфейса. Отменённый запрос не открывается снова в той же сессии.
• При смене мобильной сети и Wi-Fi нативные транспорты переподключаются автоматически. Исправлена обработка возвращения сети после её временной потери.
• Исправлен ложный тайм-аут пинга qWDTT/CSQTT и остальных нативных транспортов: подготовка соединения отделена от HTTP-проверки, первому DNS/TCP-запросу предоставлен ограниченный запас времени. Остановка теста освобождает только его ресурсы.
• У существующих профилей qWDTT/CSQTT сохраняется ID устройства при обновлении подписки и замене сервера. Новые импорты без ID используют постоянный идентификатор устройства.
• Добавлена кнопка сортировки профилей группы по пингу. «Автосортировка по пингу» включается отдельно для каждой группы и выполняется после общего теста; ручная кнопка этой группы при этом скрыта. По умолчанию автосортировка выключена.
• Убрана круглая стрелка из панели логов. Отправка логов не создаёт очередь повторных окон; ограничено ожидание logcat и обработка чрезмерно длинных диагностических строк.
• Результаты проверки хешей VK показаны возле их названий акцентным цветом. Копирование также использует цвет интерфейса. При выходе из профиля тест сразу останавливается и результаты очищаются.
• «Остановить» в управлении сервером оформлена плиткой и тусклая, когда нет активной операции. Сохранение профилей и VPS оставляет редактор открытым; выход без сохранения не записывает изменения.
• SOCKS5 и HTTP используют отдельные порты, доступ из LAN требует явного включения и авторизации в VPN-режиме. MTU по умолчанию — 1500. User-Agent автоматически содержит версию сборки; совместимость подписок Happ/Incy сохранена.
• Добавлена проверка выбранных приложений внутри ядра TUN. Привязка VK для qWDTT сохраняет сессию входа и запрашивает OAuth только при необходимости создания хешей; CSQTT использует ручные хеши.
