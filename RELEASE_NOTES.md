# qThroneMobile 2.4.2

- Автоматический выбор транспорта CSQTT: основной 2.5.0 Legacy и отдельный совместимый клиент для серверов 2.1.9 / 2.5.0 pre-release. Подключение и тест задержки используют общий путь переключения. Деплой остаётся на 2.5.0 Legacy.
- Прокрутка окон подписок отделена от жеста закрытия: окно можно тянуть только за верхнюю ручку.
- В редакторе подписки убраны отдельная полоса панели инструментов и кнопка-крестик.
- В новых релизах публикуются только APK и стандартные архивы исходников. Метаданные обновления и контрольные суммы доступны через GitHub API без отдельных файлов в списке загрузок.
- Для старых клиентов сохранён переход через релиз 2.4.1. Проверки пакета, версии, контрольной суммы и подписи APK сохранены.

APK устанавливается поверх прежней версии с сохранением профилей и настроек.

[Описание изменений CSQTT для переноса в ПК-клиент](https://github.com/ttrroyy/qThroneMobile/blob/v2.4.2/docs/csqtt-2.4.2-desktop-port.md).
