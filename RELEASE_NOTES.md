- В пустых списках деплоя qWDTT и CSQTT отображается только кнопка «Добавить VPS для деплоя».
- Новый VPS появляется в списке только после явного сохранения кнопкой в верхнем меню. Ввод полей, выбор SSH-ключа и переключение параметров больше не сохраняют черновик автоматически.
- После сохранения открывается список серверов. При возврате без сохранения новый черновик отбрасывается; при повороте экрана он сохраняется в памяти.
- Удалены полностью пустые записи «Новый сервер», оставшиеся от прежних версий. Настроенные VPS и записи с учётными данными сохраняются.
- Уточнена подпись «Удалить сервис с VPS»; удаление сохранённого VPS из списка доступно в меню сервера и не требует подключения по SSH.
